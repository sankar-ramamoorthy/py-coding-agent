# Knowledge Base Index

Start here. This knowledge base follows the raw → processed → topics lifecycle described in
`../../docs/promotion.md`, with documents shaped per `../../docs/schema.md`.

- **Looking for settled, trustworthy documentation?** Start in `../topics/`.
- **Looking for material still being synthesized?** Check `../processed/`.
- **Looking for what was captured recently but not yet reviewed?** Check `../raw/` — treat
  everything there as unreviewed input, not authority.
- **Trying to figure out which documents matter for a specific task?** See
  `[[runtime-context-map]]` — it routes a task category to the documents relevant to it, so
  you don't have to read the whole knowledge base to do one piece of work.

To validate this knowledge base (schema compliance, wikilink resolution, promotion-rule
compliance), see `../../validator/README.md`.
