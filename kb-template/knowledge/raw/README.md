# raw/

Captured, non-canonical by default. Anything landing here is an input — a note from a
conversation, a meeting, an external source — that has not yet been synthesized or
reviewed.

Documents here should have `type: raw-note`, `status: draft`, and `canonical: false`. See
`../../docs/authoring-rules.md` for how to write them and `../../docs/promotion.md` for how
a document eventually leaves this folder.

Nothing in this folder should be treated as implementation authority.
