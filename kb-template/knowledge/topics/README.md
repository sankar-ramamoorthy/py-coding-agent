# topics/

Canonical entities, cross-linked via wikilinks (Obsidian-style `[[name]]` links). A document only belongs here once it
has gone through the promotion event described in `../../docs/promotion.md` — its `status`
is `canonical` or `active`, and that status was earned by moving it out of `../raw/`, not by
editing it in place.

Anything under `topics/` should be treated as trustworthy, settled knowledge for the project
it belongs to (see its `authority` field for exactly how strong a claim that is).
